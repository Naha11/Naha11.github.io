Ally, running in the Framer editor

37 seconds · no sound · recorded in a real project

What happens in the recording

  1. The plugin panel is open in Framer, next to a page with four text layers and two images.
  2. Run audit scans the open page and reports four failures across six layers.
  3. Under Text contrast, each failing layer shows the ratio Ally measured — 2.32:1 where WCAG 1.4.3 requires 4.5:1 — and a colour that would pass, #767676 at 4.54:1.
  4. Under Image alt text, each image without a description gets a field, pre-filled from the layer name.
  5. Pressing Save writes the description into the document. The row disappears, because the problem is genuinely gone — re-running the audit no longer reports it.

Two things this recording does not show, deliberately.

Licence activation is not shown. The licence keys are issued by the store, and the store is still being reviewed, so no valid key exists yet. The paid features in the recording are real and covered by tests; only the key check is not yet wired to a live product.

Colour is never changed automatically. A colour is a design decision, often a brand one, and a shared style can reach far beyond the layer on screen. Ally proposes a value that passes and leaves the choice to the designer.
